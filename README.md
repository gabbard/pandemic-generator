# pandemic-generator

Pandemic Survival is a competitive variant of the board game [Pandemic](https://boardgamegeek.com/boardgame/30549/) where multiple teams of two play parallel games of Pandemic on identical boards, with identical card sequences, etc.  Pandemic Survival tournaments used to be sponsored by the publisher of the game, but they no longer are.  This Android phone program allows you to easily run your own Pandemic Survival tournaments without needing a moderator or going through the trouble of stacking decks.  

## To run a game

1. Get out your Pandemic board, cubes, and pawns.
1. Place all the player cards in a face-up array beside the board. I suggest arranging them by color.  If you are playing with variant Epidemic cards from Virulent Strain, include those as well.
1. You will not need Infection cards.
1. Start the program and configure your desired settings.
1. When you begin the game, it will tell you what cities to infect with starting cubes.
1. Play the game as normal. The program will tell you what cities to infect and what player cards to draw on each turn.

When playing multiple parallel games with multiple players, they should all take turns in lock-step.
The winner is whoever cures all the diseases on the earlier turn, tie-breaking by fewest outbreaks.
If no one cures all the diseases, the winner is the last team standing.

## Installing the program

1. In Github's mobile view, scroll to the bottom of this page, below the README.
2. Under releases, click "<number> tags"
3. Click the number for the most recent tag.
4. Click the `.apk` file under "Assets"
5. When the file downloads, open it with "Files by Google"
6. In the dialog which comes up, choose "Extract".
7. In the file browser, you should now see `app-debug.apk`.
8. Click it and choose to install the app.
